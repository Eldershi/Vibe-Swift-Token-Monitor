# 0.5.0 Beta 2（23）验收

## 本轮变更

- 页面短内容顶部对齐；标题栏由窗口预留，不再叠加固定 52 pt。修复前真实截图可见内容垂直居中，修复后模型页与总览正常。
- 热力图由 AppKit 可视宽度驱动补周，绘图缓存包括文档尺寸。保持 7/3 pt 方块与间距。
- 横向滚动显式处理触控板与 Shift＋滚轮，纵向交给外层页面；手动偏移不被布局/同步覆盖。
- 模型标题与中性排序菜单同排；趋势保留每日数据；移除实时速率及专用采样，兼容旧偏好。
- 新增可选 Hub 同步、已有设备绑定和本机查看；本机 Hub 仍仅监听回环，远端没有迁移或新增设备。
- 原版保留运行在 `hubMode=local`，只关闭共享 Hub 同步，未卸载或关闭其本机采集。

## 自动与实际验证

- Swift：55 项通过，包括原生容器短页顶部位置、宽度约束、NSEvent 横向滚动处理、布局后手动偏移保持；原有日期、零/缺失值、额度、偏好和 AX 图表覆盖保留。
- 最终安装包的合成日志回归通过：token 分项、固定费用、追加、截断、轮换、重启、跨月、零值、历史及源日志只读。
- Node：21 项通过，包括原始采集 envelope 标准化、额度单独更新、切换历史保留、重启去重、追加/截断/重放、跨日/月、旧工具保留、费用及 429 重试。
- 实际模型页：顶部间距正常，标题与排序同排、排序中性灰；页面菜单和首页设置均无实时速率；趋势页无额外日/月切换。
- 三年历史完整小窗宽度 320…1600 pt，含标题栏、原生控件与快照接收。resize 主线程中位数 5.13 ms、P95 8.57 ms、最大 10.22 ms；周期切换中位数 6.71 ms、P95 9.81 ms、最大 11.63 ms；快照刷新中位数 3.77 ms、最大 6.59 ms。
- 16 ms 等待之外的调度延迟中位数 3.18 ms、P95 4.11 ms、最大 13.56 ms。这不是屏幕帧率，也不证明每帧小于 5 ms。

## 验收中修正的问题

- 真实采集器的原始记录使用根级周期字段，同步模块需要 `periods` 形式；接入必须使用 `hub.ingest` 返回的标准化记录，不能直接转发原始 envelope。
- 后台读取 Hub 密钥需要自有 UI 和随包辅助程序的明确钥匙串访问控制；临时签名包更新后由 UI 刷新本应用的权限。凭据只通过辅助程序私有 stdout 管道交给 Node，不写运行配置或诊断日志。
- 同一同步轮次共享一次钥匙串读取；并发读取统计/历史不会各自启动凭据读取进程。失败结果不缓存，401 后重新读取。

## 限制

- 未宣称完成 Instruments SwiftUI 更新因果图、实际显示帧率或完整 VoiceOver 人工体验验收。
- 未进行真实账号限流、整机注销登录或长期资源压力实验；错误行为通过隔离夹具验证。有效 Claude 真实账号仍需具备账号的环境复核。
- 仅本地临时签名分发，不是公证或正式发布。多设备同步沿用现有 Hub 和设备身份；更换 Hub/绑定需先明确处理已有切换基线，不能静默重置。

## 最终真实同步

- 连续 7 轮成功刷新，约 629–2996 ms/轮；Hub 缓存包含 3 台唯一设备、110 个历史日期，本机身份恰好一次。Hub 中本机总量与最近已上传基线一致。
- 完整设备页已检查：3 台设备恢复，在线/过期状态各自保留；界面显示“已连接 · Hub 多设备同步”。原版应用仍运行在仅本机模式。
- 额外原生窗口集成覆盖 320/600/1000/1600 pt 及缩回 600 pt，断言热力图文档宽度始终覆盖实际可视宽度，超出量小于一列，绘图缓存尺寸同步。
- Hub 使用独立、无连接复用的 HTTP(S) 请求；回归覆盖 JSON 鉴权、禁止重定向及取消关闭连接。LaunchAgent 使用 Standard 调度；早期 Background 候选包出现辅助程序及请求超时，不能以终端单次成功代替受系统管理进程的验收。
- 物理拖窗/触控板操作的自动控制曾被“用户改变窗口”状态保护中断；未将中断尝试算作通过。原生滚轮事件处理、真实窗口布局和完整交互耗时已有测试覆盖。
