# 0.5.2（35）发布记录

日期：2026-09-15。正式版本，非预发行；Apple Silicon，最低 macOS 26，构建与测试使用 macOS / Xcode 27。

## 变更

- 热力图与趋势共用活动详情，首页两个栏目仍可独立显隐和排序。每日明细按年/月展开，年月小计来自日记录，缺失数据标记“已记录”；展开选择在本次运行内按来源及 Agent 保持。
- 柱状图只命中实际非零柱形，高亮共用胶囊几何及内部描边，并适配明暗外观和极短柱；零值、缺失及无障碍语义保留。玻璃控件优先响应，顶部正文可滚入玻璃后方。
- Agent 菜单原生勾选当前选择；布局按首页栏目、额度、设备分组，恢复默认操作放在末尾；首页图标保持独立，活动使用剪贴板图标。
- 设置/关于支持 GitHub 正式版检查，自动检查默认关闭，开启后每 6 小时检查；下载安装始终确认。使用 Sparkle 2.10.0，归档和更新清单均有 Ed25519 签名。
- 接入用户提供的 Apple Icon Composer 分层应用图标，由 actool 生成浅色、深色、着色资源及 ICNS 兼容图标。
- 修复 HubClient 停止连接与迟到异步请求交错导致的 URLSession 失效异常：关闭后拒绝新请求、取消现有任务，session 失效延后到析构。
- 整理开发文档的长期规则、诊断入口和历史记录；ZIP 名称改从包内版本/构建生成。

## 兼容与升级

继续使用 `local.tokenmonitor.native.beta`、Beta 数据目录和后台 LaunchAgent；Beta/β 为兼容通道标识，展示版本为 0.5.2。偏好 schema 3 不变，旧趋势页面映射到活动，首页栏目偏好保持独立。旧 0.4.1 客户端不被替换。

0.5.1 及更早版本没有应用内更新入口，首次升级需下载 ZIP；从 0.5.2 开始可检查后续正式版本并确认安装。本次不自动安装替换本机应用。
