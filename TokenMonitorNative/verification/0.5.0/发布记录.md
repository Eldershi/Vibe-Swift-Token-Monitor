# 0.5.0（30）发布记录

日期：2026-09-14。平台：Apple Silicon；最低 macOS 26，实际构建与测试为 macOS 27 / Xcode 27 SDK。

## 变更

- 从 0.4.1 Hub 查看客户端发展为独立本机 Codex / Claude Code 采集应用；随包 Node/Tokscale、只读额度、独立后台及可选共享 Hub 同步。
- 保留 Hub 设备身份和历史基线；手动 Hub 凭据与统计配置分离，不访问 Hub 钥匙串。
- 修复窗口布局、宽热力图、趋势滚动；简化详情及导航，保留自定义主题与栏目排序，移除实时速率。
- 设置主题色仅在控件内部传递；栏目使用原生拖动会话，顺序持久化。
- 精简工程文档与维护入口，说明独立衍生关系、MIT 后台复用、固定来源及许可；发行包包含第三方声明。
- 公开提交基于已清理的主分支，不引入旧分支祖先。未启用的上游 OAuth 常量不随包分发，Claude 登录刷新继续禁止。

## 安装与限制

安装名称仍为 `Token Monitor Native Beta.app`，沿用独立 Bundle ID、目录和服务，避免丢失已有 beta 设置或覆盖旧 0.4.1。升级、后台停用与 Hub 回退见[管理说明](../../BETA.md)。

当前是 ad-hoc 签名，未公证、没有自动更新。公开发布不代表所有环境均已验证：真实 macOS 26、有效 Claude 账号、实际注销登录、完整 VoiceOver、持续物理拖窗/触控板及长期资源占用仍待补充。既有真实性能和生命周期结果见[构建 23 记录](../0.5.0-beta.2/验收.md)，本次没有重复该全套测量，也不声称屏幕 FPS。
