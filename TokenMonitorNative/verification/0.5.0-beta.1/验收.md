# 独立 Beta 验收

日期：2026-09-13。基线：0.4.1（21）；候选：0.5.0 Beta 1（22）。

## 已验证

- Swift 原有 50 项及新增 2 项端点校验测试通过。后台 13 项测试通过：认证、禁止外部 ingest、SSE、暂停持久化、端点轮换、损坏配置保留、Claude 401/429/503、凭据不可用、真实零额度及 Codex 禁止 RPC 回退。
- 固定采集器的合成日志测试覆盖 Codex token 分类、Claude token 分类、给定价格费用、重复进程扫描、月边界、每日历史、追加、截断、归档移动和源文件只读。合成 460 tokens 的费用为 $0.00114；不使用真实会话样本。
- 真实 SMAppService LaunchAgent 已注册并运行，后台与采集器来自 beta 包内路径。第二个 helper 被文件锁拒绝；模拟后台崩溃后由系统重新启动，端点密钥轮换，暂停状态保留。恢复和立即刷新能产生新的成功采集时间。
- 实际退出 beta 界面后，后台继续采集。另一次短暂退出旧 Electron 软件，在两者界面均未运行时，beta 完成新的真实采集，随后恢复旧软件。
- 本机 Codex 真实用量与额度获取成功；Claude 当前无可用登录，显示未配置，已用合成额度和日志测试其可用／失败路径。
- CUA 检查真实小窗、设置及暂停按钮；暂停后画面显示“采集已暂停”和最近成功时间。
- 开发验证前后，稳定版二进制、稳定版设置和旧软件设置的 SHA-256 一致。合成扫描前后原日志文件逐一哈希相同；旧软件历史在其运行时会自行刷新，未以静态哈希宣称这些文件没有变化。

## 性能

完整 beta 小窗，1095 天合成历史，320…1920 pt，包含工具栏、玻璃操作、时钟和快照接收：

| 操作 | 中位数 | P95 | 最大值 |
| --- | ---: | ---: | ---: |
| resize 同步主线程工作（120 次） | 4.62 ms | 9.07 ms | 14.83 ms |
| 周期切换同步工作（60 次） | 6.39 ms | 7.52 ms | 7.85 ms |
| 快照接收同步工作（6 次） | 2.92 ms | 12.73 ms | 12.73 ms |
| resize 超出 16 ms 请求节拍的调度延迟 | 1.14 ms | 1.27 ms | 3.27 ms |

上述数据不包含主动等待时间，不是屏幕 FPS，也不代表所有交互都达到 5 ms。后台运行独立于主线程。

## 验证中发现并修复

- 首次服务状态为 `notFound` 时仍需尝试注册，不能只处理 `notRegistered`。
- launchd 可传入相对 argv；helper 通过 `_NSGetExecutablePath` 定位包内 Node，不能按 `argv[0]` 推导安装目录。
- 重新启动采集前等待上一采集器取消完成，避免多个扫描同时写缓存。
- 同步目录可能给构建产物添加 Finder 扩展属性；在临时目录签名，安装复制后清理扩展属性再验证原签名，不重新签名掩盖内容变化。
- 固定采集器使用持久化消息缓存，日志截断后保留已观察历史；测试应验证不重复累计，而非要求历史消失。

## 最终产物与停用检查

- 最终安装版与 dist 中前台、helper、后台入口、Node 和许可证的 SHA-256 分别一致，ZIP 包含完整 Tokscale 许可证。
- ZIP 大小 48,995,349 字节；SHA-256：`7c3a6747f3d168dd9efadddf91491dde09c3cf885ae9da86c13a315fa9c8a322`。
- 实际点击停用后，后台进程和端点消失；退出/重新打开及更新 beta 后仍保持停用。随后用设置中的启用按钮恢复采集。
- 最终窗口无旧软件启动入口；后台状态与成功时间拥有独立、可更新的无障碍值。断网及锁定 Keychain 的模拟覆盖计入 13 项后台测试。

最终后台短采样（12 次，约每秒一次）：Node CPU 均值 4.52%，最高 50.5%，RSS 最高 214.4 MiB。该值为短时 Node 进程采样，不含短寿命采集子进程峰值，不能代表长时间平均功耗。
