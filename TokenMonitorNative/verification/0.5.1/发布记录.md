# 0.5.1（33）发布记录

日期：2026-09-15。正式版本，非预发行版；Apple Silicon，最低 macOS 26，实际构建和测试使用 macOS 27 / Xcode 27 SDK。

## 变更

- 支持简体中文和英语，默认跟随系统及单应用语言设置；不支持的语言使用英语，日期和数字沿用系统地区。
- 设置整理为通用、布局、数据、关于；数据页合并本机采集、账号额度、Hub 同步和后台运行。
- 首页额度默认展示有效报告中的 Codex 常规窗口；布局中可动态定制至少一项，详情保留专项模型额度，选项随报告新增或消失。
- 首页固定用量摘要，精简重复周期与采集诊断；详情入口限定标题和图标，连接页脚靠右。设备系统图标缩小并居中，详情显示相对最高设备用量条，首页提供默认关闭的开关。
- 热力图和柱状图共用原生透明悬停提示；柱状图锚定柱顶，胶囊轮廓沿内部描边，强调色适配深浅外观。首页和详情同步使用同一组件。
- 修复小窗 320 pt 最小内容宽约束及深色顶部背景；嵌套原生宿主及时同步文字明暗外观。
- 安装脚本支持版本化文件名与旧包归档；维护开发文档、本地化检查及设备素材署名。

## 兼容与限制

正式版继续使用 `local.tokenmonitor.native.beta`、既有 Beta 数据目录和后台服务；安装名称和菜单栏 β 是兼容通道标识，完整版本为 0.5.1。偏好 schema 3 不变，新字段缺失使用默认值；旧 0.4.1 客户端不受替换。本次未自动安装或操作正在运行的后台。

当前仍以 Codex 为重点，ad-hoc 签名、未公证、无自动更新。macOS 26 真机、真实 Hub 验证失效/绑定/启停全流程、实际注销登录、完整 VoiceOver、物理拖窗及长期资源验收未在本次重复。后台版本上报字符串仍有旧值，保留在[技术债](../../../docs/CURRENT_ISSUES.md)中，不影响包内显示版本。
