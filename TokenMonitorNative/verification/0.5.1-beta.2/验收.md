# 0.5.1-beta.2（32）额度展示定制

## 行为

- Beta1 首页和详情共用所有额度窗口，并随工具筛选。Beta2 首页默认仅展示有效 Codex 常规额度，实际报告 5 小时窗口时才展示；不按订阅计划名称生成或屏蔽额度。
- Layout 新增“首页额度”，默认自动；自定义从有效报告生成开关，至少保留一项。选择独立于顶部工具和统计周期，详情展示全部有效额度，含 Spark 与其他模型额度。
- 新有效报告未包含的额度不再出现在选项/详情/首页；不硬编码模型名或停用日期。新的同协议额度自动进入选项和详情，默认不加入自定义首页。上游接口结构发生不兼容变化仍需适配，不能承诺任意新协议自动识别。
- 自定义选择与当前选项取交集；交集为空时回退到现有 Codex 常规额度，若仅有其他额度则取首个现有项。自动模式没有 Codex 常规额度时不把 Spark 提升为默认；没有可用额度时隐藏栏目并禁用定制入口。瞬时断连延续既有缓存规则，选项移除以有效新报告或报告过期为依据。
- 新增可选偏好 `homeQuotaSelection`，schema 3 向后读取兼容，旧配置默认自动；保存额度类型标识，不保存账号身份。类型标识不含百分比、重置时间或翻译文字。保留已选项以便暂时离线后恢复，用户下次编辑时保存当下有效选择。
- 保留后台公开字段 `limitId`、`additional`、`windowMinutes` 至原生缓存，支持动态识别。旧 Hub 缺少元数据时按非模型周期标签作兼容判断；未知命名额度保守归入专项额度。未来同种 kind 内不同 duration 的额度沿用该周期类型选择。
- 有效额度不再要求同时有日志用量来源；实际零额度保留，未报告、无效百分比和负剩余额度不成为选项。
