# Device operating system icons

Windows, Linux and the fallback Mac logo are Icons8 iOS Filled PNG icons (96 × 96).
Icons by [Icons8](https://icons8.com). Attribution also appears in the app's About settings.

Sources:
- https://img.icons8.com/ios-filled/96/windows-10.png
- https://img.icons8.com/ios-filled/96/linux.png
- https://img.icons8.com/ios-filled/96/mac-os.png

Apple platforms use an available native Apple symbol first. Other operating systems use the native macbook symbol.
