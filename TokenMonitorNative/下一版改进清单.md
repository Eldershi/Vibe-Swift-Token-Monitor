# Token Monitor Native 0.2.0 改进清单

来源：用户反馈（公开版本不保留对话分享链接）。本文件记录本次已实施的需求与验收标准。

## 已确认的六项反馈

| 项目 | 改动 | 验收标准 |
|---|---|---|
| 分割线 | 移除小窗顶部控制区下方、底部操作区上方两条横向贯通线；保留内容中间有左右留白的分隔线 | 窗口上下不再被贯通线切成三块 |
| 窗口标题 | 隐藏红绿灯旁的 Token Monitor Native 文字 | 保留系统关闭、最小化、缩放及标题栏拖动；应用在菜单与辅助功能中仍可识别 |
| 时间范围 | 去掉可见的“时间范围”文字，仅显示今天／本月／总计；使用系统原生控件的 Liquid Glass 呈现 | 三项可直接选择；读屏仍有时间范围标签；不把玻璃控件嵌入另一层自定义玻璃 |
| 置顶 | 移除主界面的图钉按钮，保留设置中的“小窗口置顶”开关 | 设置可控制置顶，状态持久化，主界面不占用空间 |
| 首页信息 | 补齐总 token、额度、模型使用情况、活动热力图、按日趋势 | 展示真实数据；缺失与零值区分；费用与额度分别标注；小窗内可滚动查看 |
| 小窗内导航 | 把总览、设备、模型、趋势整合回小窗，移除“打开统计窗口”入口和独立统计窗口 | 底部原生菜单可直接选择页面；无需打开第二个统计窗口；筛选状态共享 |

## 代码对应位置

- `Sources/TokenMonitorNative/Views.swift`：单窗口四页导航、额度、模型、热力图、每日趋势；只保留内容内部的分隔线。
- `Sources/TokenMonitorNative/App.swift`：隐藏可见标题、原生 NSToolbarItemGroup 周期控件，移除独立统计窗口及入口。
- `Sources/TokenMonitorNative/SettingsView.swift`：沿用原生置顶 Toggle。
- `Sources/MonitorCore/Quota.swift`：额度脱敏模型、状态及热力图日历映射。
- `Sources/TokenMonitorNative/LiveVerification.swift`：增加同快照额度对照。

## 实施顺序

1. 精简小窗外观：外围分割线、标题、时间范围、置顶入口。
2. 完成小窗内部导航，将设备、模型和趋势改为适合窄窗口的布局，再移除独立统计窗口。
3. 核对现有 Hub 的额度字段，明确单位、剩余／已用、重置时间及过期状态。只接入统计展示所需字段，不顺带保存账号凭据。
4. 用现有历史数据补齐活动热力图和首页按日趋势；空缺显示无数据，真实零值保留为零。
5. 重新验证浅色／深色、窄窗口与缩放、键盘、辅助功能、后台断连，以及升级后设置和密钥保留。

## 需延续的约束

- 内容保持清晰的普通系统背景；玻璃只用于导航与操作层，不制作玻璃内容卡片或嵌套玻璃。
- 控件保留系统原生交互，不仿制滑块或分段控件。
- 用户说的 Codex／Claude 选择属于“工具”筛选；“模型”页显示具体模型用量，二者不能混淆。
- “不需要独立统计窗口”针对统计页面；连接和通用设置仍使用原生设置窗口。
- 原应用后台依赖是另一项架构问题。这份界面反馈没有确定后台整合方案；完成以上六项不会自动消除对原 Token Monitor 采集与 Hub 的依赖。

## 完成状态

六项功能已实现，交付版本 0.2.0，构建 8。自动测试、真实接口与界面验证详见验收记录。系统工具栏可能绘制自己的边缘阴影；应用不再绘制顶部或底部的贯通分隔线。

## 0.2.1 追加反馈：已实施

顶部透明并让周期控件靠右；底部改为无条状背景的原生玻璃菜单及按钮。内容可从控件下方滚动。热力图保持圆角正方形，灰色空白格无点无描边；各内容模块以留白分隔线区分；日／月趋势均改为曲线，缺失处断开。版本 0.2.1，构建 9。

## 0.2.2 追加反馈：已实施

底部改为 SF Symbols 图标胶囊与两个圆形玻璃按钮，菜单直接列出选项。热力图固定格子并支持横向历史，趋势改为固定细胶囊柱；增宽容器展示更多日期，保持高度。删除各模块解释文字。版本 0.2.2，构建 10；具体验证边界见验收记录。

## 0.2.3 追加反馈

显式单层系统玻璃材质、趋势最新日期绑定、柱子加粗并收紧间距、热力图外框内日期标签、隐藏两张图的横向滚动条均已实现并安装。实际界面验收等待系统钥匙串授权完成。

## 0.2.4 追加反馈：已实施

热力图仅显示月份；趋势使用更密的 5 pt 胶囊柱，隐藏零基线并保留右侧 0；横向滚动条使用 never 策略彻底隐藏；页面胶囊恢复正常大小和完整图标菜单。版本 0.2.4，构建 14。


## 0.2.5 本轮细化

- 底部三枚入口统一为 44 pt 单图标圆形玻璃按钮；取消左侧胶囊和省略号，齿轮增至 20 pt。
- 页面和来源菜单保留 10 pt 间距，每项包含 SF Symbol。macOS 27 显式设置菜单图标可见，旧系统继续用 NSMenuItem.image。
- 成功连接／有效设备上报显示绿色，过期上报显示橙色，保留文字。
- 来源依据有效设备报告和实际统计字段筛选，正常零用量不隐藏；空额度、空模型区块从首页隐藏。全局断连时保留最后有效统计。
- 参考截图设置 320 pt 最小内容宽度，不锁定宽高比；保留窗口位置和独立高度。


## 0.2.6 首次历史位置与工具菜单

- 活动热力图使用确定宽度的普通 HStack，避免延迟布局估计宽度改变初始偏移。
- 活动和趋势共享滚动定位修饰器，内容宽度／可视宽度变化后再次对齐末端；进入页面、切换工具时重置到最新。用户主动横向浏览后停止自动定位。
- 趋势最右增加 8 pt 内容留白，避免末柱紧贴裁切边缘。
- 工具菜单包括“全部工具”在内均不显示图标；外侧脑形入口及页面菜单图标保留。


## 0.3.0 首页定制、详情页与主题色

- 设置首页标签提供七个栏目开关、上下排序按钮、恢复默认布局；隐藏设备为默认值以保持旧首页顺序。
- 首页按持久化顺序生成栏目，设备可以加入；所有栏目标题可进入详情，全部隐藏时提供设置入口。
- 新增用量／实时速率／额度／活动详情；沿用设备、模型、趋势页面，非首页均有返回总览入口。
- 原生主题色 Picker 提供跟随系统及七种颜色；图表、额度进度和交互强调同步更新，状态语义色不受影响。
- 设置迁移到 schema 2，自动备份旧配置，保留连接、工具、时间范围、窗口偏好；未知栏目／颜色容错。
