# UI 约束
- 设置/通用使用 SF Symbols 7.2 导出的原始 `ReferenceGear` 符号资源（bold 字重），不得用系统同名 `gear` 或加粗近似替代，设备 `server.rack`，首页固定用量标识 `binoculars.fill`，额度 `timer`，数据 `externaldrive`；设置标签固定按“通用”“布局”“数据”“关于”排列，英文 General / Layout / Data / About。首页详情入口使用独立栏目图标，仅标题文字和图标可点击，中间空白不响应；用量标识不进入详情。
- 图标默认使用 Apple SF Symbols；设备名称前的系统标志为有限例外：Apple 优先原生标志，Windows/Linux 使用获授权的 Icons8 单色模板素材，未知系统用 `macbook`；使用系统原生控件。玻璃仅用于浮动导航/操作，不用于内容卡片、不嵌套；普通按钮在 `GlassEffectContainer` 内各用一次 `glassEffect`，不再叠加玻璃按钮样式。
- 底部左侧为页面/工具两个 44 pt 点击区域组成的液态玻璃胶囊，中间 20 pt 高分隔线；右侧刷新、设置各为 44×44 pt 圆形玻璃按钮。每组只一层玻璃，间距 10 pt，图标 19–20 pt。页面/工具直接 NSMenu 操作，页面带图标，工具纯文字、当前项原生勾选（含全部工具）；保留工具提示与无障碍标签。正文不重复放刷新/后台设置按钮。
- 设置页标题、说明与状态文字保持系统黑灰色，主题色仅在按钮、开关及选择控件内部传递，不给整个 Form/TabView 传主题色；“布局”内首页可见性与通用共用 small 控件尺寸。“数据”页使用单一滚动表单，按本机采集、账号额度、Hub 同步、后台运行分组，Hub 同步组不放说明性段落；首页与关于的连接状态共用同一文字。
- 详情页标题行只显示左侧返回箭头与页面名，返回保留无障碍标签；不附加工具/周期后缀。模型排序仍在同一行右侧。
- 最小内容宽 320 pt，由原生窗口同时约束交互缩放与旧尺寸恢复，不能只依靠 SwiftUI 内容 frame；高度独立，不设最大宽度。正文滚动视口延伸到透明标题栏后方，不保留整条顶部遮挡；不重复添加标题栏内边距，短页顶部对齐。模型标题与排序同排，排序靠右、系统中性色；趋势只展示每日数据，保留全局今天／本月／总计。
- 热力图固定 7 pt 方块、1.5 pt 圆角、3 pt 间距，视口含月份标签高 104 pt；宽窗按实际视口向左补缺失日期。每日趋势固定 5 pt 柱、约 7 pt 日期槽位；月份横轴，圆角外框包住绘图区与右侧纵轴，保留零标注但不画零基线。拉宽只显示更多日期，不拉伸图形或增高。
- 历史偏移归 AppKit；进入/换来源/初始数据晚到定位最新，手动浏览后布局与同步不重置。横向滑条始终隐藏但保留手势；页面右侧滑块 5 pt 浅灰、至少 14 pt 操作区，自动淡出且无常驻轨道。验证“始终显示滚动条”场景，不修改系统偏好。
- 正文不加开发解释，保留错误、缺失和离线状态。连接/有效报告绿色，过期橙色；隐藏不可用/未报告来源，保留真实零值和断连历史缓存。批量 Canvas 绘图保留 AXChartDescriptor，不恢复大量独立布局的图形节点。
- 首页用量固定在顶部，保留摘要样式，不可隐藏或排序，不提供详情页；工具名后不重复周期。其他栏目为额度、设备、模型、热力图、趋势，均有详情，显隐与顺序独立持久化于 schema 3，设备默认隐藏。右侧手柄原生拖拽排序并保留无障碍移动操作；过滤旧 `rate` 值，旧详情回总览。主题默认系统，支持 ColorPicker 任意 sRGB 持久化，不覆盖语义颜色。

共性实现与验收原则见 [README 开发须知](README.md#开发须知)；连接页脚全宽右对齐，只显示“已连接Hub”或“已连接本机”及实际错误，去掉来源/数据截至说明。这里仅维护 UI 规格，不追加版本过程记录。
- 界面支持简体中文与英语，语言由 macOS（含单应用覆盖）选择，未匹配支持语言时使用英语；不保存应用语言偏好。“通用”按窗口、外观与辅助功能、语言分组，语言只保留系统“语言与地区”入口。动态状态、错误与无障碍文本共用原生本地化资源；日期与数字遵循系统地区。首页空状态占满内容宽度并居中。
- 首页额度默认仅 Codex 常规窗口，Layout 额度定制至少选一项，选项按有效报告动态生成；未报告不显示，零值保留。详情展示所有有效额度，含专项模型；额度选择不随顶部工具/周期改变。
- 设备采集提示必须标明工具；全部工具下忽略无历史用量且来源缺失的工具，曾有用量后丢失来源仍提示。单独选择某工具时保留其明确缺失提示。
- 活动热力图悬停仅命中实际方块：鼠标上方显示独立、不抢焦点的两行提示（用量、日期），不增加正文行；细描边与轻微高亮按深浅主题、增强对比度适配。滚动、切页、切工具及数据更新清除悬停，不重建基础图形或重置偏移。
- 设备系统标志为 13.5 pt，与设备名称独立成组垂直居中，不使用固定基线偏移；设备详情显示按当前工具/周期相对最高设备的原生用量条。首页用量条由布局/设备开关控制，默认关闭；零值为空条，缺失/无效或上一周期值不参与比较。偏好 showHomeDeviceUsageBars 沿用 schema 3。
- 小窗正文可滚入透明标题栏后方，初始留白不重复计算，深色模式不出现独立的顶部覆盖层。
- 正文/历史图表的原生宿主必须在 effectiveAppearance 变化时立即更新 SwiftUI colorScheme，不等待数据刷新；禁止复制整份 EnvironmentValues 冻结外观，地区格式与主题色显式传递。热力图悬停描边、微光和提示框边框均跟随应用主题色，未自定义时跟随系统 accent；不固定为纯黑白。
- 首页设备分项不显示采集诊断（含等待日志/用量），无障碍摘要同步省略；详情页仍保留。
- 图表浮窗使用原生标签先计算尺寸，最终尺寸/位置一次设置，禁用原生弹出和隐式动画；柱状图与热力图共用实现。柱状图浮窗锚定柱顶居中，不随鼠标纵向位置移动；仅实际非零柱形命中，柱顶空白、间隙、轴标签与零值/缺失日期不触发；零值/缺失仍保留无障碍数据，描边跟随主题色。
- 首页栏目标题右侧详情图标跟随应用强调色，望远镜保持中性。柱子与高亮必须共用几何及胶囊半径，高亮沿柱形内部描边，不添加外扩圆角矩形。
- 首页/详情图表共用窗口内的原生、鼠标透明浮层，不创建子窗口；浮层按全部滚动祖先计算可见命中与坐标。图表变更必须同时检查首页热力图/柱状图与对应详情，不以单页检查替代。

- 趋势与热力图共用“活动 / Activity”详情，热力图 / Heatmap 在上、趋势 / Trends 在下，各有分组标题；旧趋势页面偏好映射到活动。首页 activity/trends 栏目 ID、显隐和排序保持独立，两个标题入口指向活动，页面菜单只保留一个活动入口。
- 布局按功能分为“首页栏目 / Home Sections”“额度 / Quota”“设备 / Devices”三个独立组。额度/设备控件名称注明首页适用范围，以后详情控件归到对应功能组；不新增占位开关。恢复默认布局独立放在所有功能组之后。
- 浮动控件遮挡标记按各个现有 44 pt 按钮区域布置，标记不参与点击；图表通过窗口坐标查询遮挡，鼠标进入控件立即清除提示与高亮，不扩大到控件间空白。标记命中同时限制 bounds 与可见范围，不能仅依赖 AppKit visibleRect（可能超出自身 bounds）。

- 首页热力图图标为 `calendar`，趋势为 `chart.xyaxis.line`，图标与详情目标独立；活动页导航/菜单图标为 `waveform.path.ecg.text.clipboard`。
- 柱形高亮用主题色在 sRGB 中向黑混合 30%（浅色）或向白混合 45%（深色），描边 1 pt，增强对比度 1.5 pt，且不超过柱高；内缩半线宽并同步减小半径。极短柱的内路径退化时填充原胶囊轮廓；所有高亮像素裁剪在原柱形内。原生高亮层启用 layer backing，保持在 Canvas 宿主上方，验收须包含可见像素而非只有命中状态。

- 时间范围控件保持原生单选、悬停、按压、键盘与无障碍反馈。动画候选只在隔离诊断入口验证，未验收前不进入正式界面；禁止私有 API、全局动画开关或反复清理图层动画。

- 软件更新放在设置/关于；不显示检查说明或上次检查时间，“检查更新”与 GitHub 版本入口同处末行，状态和可用版本的安装操作位于其上方。自动检查默认关闭，仅查本仓库正式 Release；开启后应用运行时每 6 小时检查，下载安装必须确认，不静默替换。旧版本缺少签名清单时显示 GitHub 下载说明，不绕过签名验证。预览/测试入口不得自动联网检查或触发更新安装。

- 活动页图表下的用量明细按年/月/日倒序展开，默认仅最近有记录年份展开到月；年月整行可点击，多组可同时展开。日行省略年月但 AX 保留完整日期。小计来自有效日值，缺失不计零且标注“已记录”；忽略图表前置补白。展开选择仅本次运行按来源/Agent 记忆，不写入偏好，刷新与新月份不重置既有选择；年与月标识必须区分，避免一月与年份起点冲突。

- 顶部原生工具栏控件保持现有样式与操作；内容可从控件之间及玻璃下方透出。图表仅按标题栏原生 NSControl 的自身可见区域屏蔽悬停，不把整条标题栏作为遮挡区。

- 应用图标使用 Resources/Token Monitor.icon 原始 Icon Composer 文档；保持图层、材质及配色，使用 Apple actool 编译主包 Assets.car 和兼容 ICNS，合并工具生成的 CFBundleIconName/CFBundleIconFile 后再签名。不得以静态 PNG 替代分层图标或覆盖界面符号资源包。
