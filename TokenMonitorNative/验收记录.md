- 当前只有一台设备连接，未接入额外真实设备。部分设备过期、零用量、计数回退和多设备匹配速率由合成样本自动测试覆盖。
- 断线、错误密钥、SSE 不支持、Hub 重启及睡眠／唤醒使用可控网络与回调测试；没有让正在服务的真实 Hub 停机，也没有主动让整台 Mac 睡眠。
- macOS 26 的实际设备尚未测试；构建时按 26.0 做 API 可用性检查，当前运行验证在 macOS 27 测试版完成。
- VoiceOver 已验证辅助功能树和动态标签。尝试启用当前系统的 VoiceOver 未进入可确认的语音导航状态，完整读屏操作与发音验收仍需人工补测，不能称为已全覆盖。
- 未替换用户桌面壁纸。内容采用不透明的系统内容背景；实际界面检查覆盖当前壁纸和系统明暗外观。明暗壁纸的完整矩阵仍需补测。
- 尚未进行长时间能耗测试、其他 CPU 架构测试、外部网络/Tailscale 部署、公开分发签名与公证。在线 Sparkle 更新仅保留服务接口，未启用。
